- `nohup app >/dev/null 2>&1`
  - `nohup`:  让app的生命周期与shell脱钩
  - `>dev/null` 把主命令的stdout 重定向到null
  - `2>&1` ： 由shell解释，把`2`=stderr pipe 到 `&1`. `&`a修饰以区分普通命名文件。

| 工具     | 主要作用                            | 是否自动后台运行 | 是否脱离终端会话 | 是否处理输入输出                   |
| -------- | ----------------------------------- | ---------------- | ---------------- | ---------------------------------- |
| `nohup`  | 忽略 `SIGHUP`                       | 否               | 不完全           | 会自动处理终端 stdin/stdout/stderr |
| `disown` | 从 Shell 作业表中移除任务           | 否               | 不完全           | 不处理                             |
| `setsid` | 创建新的 Unix session，脱离控制终端 | 否；`-f` 会 fork | 是               | 不处理                             |

```bash
# using function ,#@ to wrppaer  args.
typora() {
    setsid -f env \
        GTK_IM_MODULE=fcitx \
        XMODIFIERS=@im=none \
        /usr/bin/typora --ozone-platform=x11 "$@" \ # fcitx5 x11 fixup  
        </dev/null \
        >>"$HOME/.cache/typora-start.log" 2>&1
}

alias tp='typora'
```
