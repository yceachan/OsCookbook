# Windows ricing codebase

这里集中维护 Windows 桌面、终端和快捷键的 ricing 配置。

## 约定

- 每项功能放在独立目录中。
- 提交可审计的配置与源码，不提交仅能执行、无法审阅的本机二进制文件。
- 每项功能提供幂等的 PowerShell 安装脚本，以及可恢复原配置的卸载脚本。
- 默认配置不写死用户名或机器专属路径；机器差异通过安装参数或本地生成的配置文件表达。
- 安装前备份被修改的系统或应用配置。
- README 记录安装、卸载、数据位置和工作原理。

## 组件

- [`WT_PD_drawer`](./WT_PD_drawer/)：`Win + \`` 唤出的独立尺寸 Windows Terminal 下拉窗口。
