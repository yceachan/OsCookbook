# 禁用美式键盘布局

适用于中文界面、使用第三方输入法的 Windows。

```powershell
$list = Get-WinUserLanguageList
$enUS = $list | Where-Object LanguageTag -eq 'en-US'

if ($enUS) {
    [void]$list.Remove($enUS)
    Set-WinUserLanguageList -LanguageList $list -Force
}
```

检查：

```powershell
Get-WinUserLanguageList | Format-List LanguageTag, InputMethodTips
```

确认仅剩中文及第三方输入法后，注销并重新登录。
