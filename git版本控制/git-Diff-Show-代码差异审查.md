### . `git diff`：比较两个状态之间的差异

- **用途**：比较两个 Git 对象（提交、树、工作区、暂存区等）之间的文件内容变化。
- **常见用法**：
  - `git diff [file]`：比较工作区与暂存区,添加文件则只显示单一文件。
  - `git diff [file] --cached`（或 `--staged`）：比较暂存区与 HEAD 提交。
  - `git diff [file] <commit1> <commit2>`：比较两个提交。
  - `git diff [file] <commit>`：比较工作区与指定提交。
- **输出**：默认只显示文件差异补丁（除非使用 `--stat` 等选项），不包含提交元数据（作者、日期、提交信息）。
- **本质**：它是一个“比较工具”，需要你指定**两个**参照点。

###  `git show`：显示一个 Git 对象的详细信息

- **用途**：展示一个 Git 对象（通常是 commit，也可以是 tag、blob、tree）的详细内容。
- **常见用法**：
  - `git show <commit>`：显示该提交的完整信息：作者、日期、提交信息以及该提交引入的补丁（相当于 `git log -1 -p <commit>`）。
  - `git show <tag>`：显示标签信息。
  - `git show <blob>`：显示文件内容。
- **输出**：默认包含提交元数据 + 补丁（对于 commit 而言）。如果只想要补丁，可以加 `--no-patch` 或 `-s`，但通常我们需要补丁，所以默认行为正好符合需求。
- **本质**：它是一个“展示工具”，针对**单个**对象，自动展示该对象的全部相关信息。
